# To-Do-List
📝 A simple and user-friendly To-Do List web application built with Python Flask and SQLite. Users can add, edit, delete, and complete tasks with due dates, scheduled task times, difficulty levels, and time tracking.

Features:
- Difficulty: 😊 Easy / 😐 Moderate / 🔥 Hard
- Time Taken: minutes spent completing the task
- Task Time: time when the task should take place (9:30 AM/PM)
- Due Date
- Add, Edit, Complete/Undo and Delete.
