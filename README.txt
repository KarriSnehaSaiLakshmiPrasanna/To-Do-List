UPDATED TO-DO LIST PROJECT

Features:
- Difficulty: 😊 Easy / 😐 Moderate / 🔥 Hard
- Time Taken: minutes spent completing the task
- Task Time: time when the task should take place (9:30 AM/PM)
- Due Date
- Add, Edit, Complete/Undo and Delete

Run in VS Code:
1. Open terminal in the folder containing app.py.
2. pip install -r requirements.txt
3. python app.py
4. Open http://127.0.0.1:5000

If you have an OLD todo.db from the previous project, delete it once before running this version.
